# Kodit.io

Kodit.io was a Helsinki-based proptech and "iBuyer" that used machine learning and automation to
make instant cash offers on residential property, buying homes directly from sellers and reselling
them, with operations in Finland, Spain and Poland. Founded in 2017 and backed by Speedinvest among
others, it rebranded to **Rive** in 2022 after a EUR 23M Series A.

**Status: defunct.** In January 2024 Rive (formerly Kodit.io) transferred its entire Finnish real
estate brokerage business to **Neliöt Liikkuu LKV**, and the Kodit.io LKV entity subsequently
entered bankruptcy proceedings in late 2024. The `kodit.io` domain has lapsed to an unrelated
registrant; `rivekodit.fi` now redirects to the acquirer.

The company operated a consumer-facing marketplace only. It never published a public developer
portal, API documentation, SDKs, or machine-readable API artifacts, so this repo carries no API
artifacts — only the identity record in `apis.yml` and the negative discovery probe in
`well-known/`.

Backed by: speedinvest
